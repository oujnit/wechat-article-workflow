# 脱敏与公开边界

采用独立干净目录构建公开版，没有复制原目录、Git 历史或聊天原文。原项目工作文件保留在本机。

| 原始内容 | 处理 |
|---|---|
| 公众号名称、作者身份 | 改为通用项目名，作者从服务器环境读取，默认空 |
| 本机用户名、绝对目录、SSH 别名、服务器 IP | 不发布；使用配置变量与通用路径 |
| config.env、Token、AppID、Secret、私钥 | 不复制，示例值为空 |
| 素材 URL、media_id、真实回执、发布结果 | 不复制；运行时只写忽略目录 |
| 会话和工具输出 | 仅发布流程摘要，不公开原始记录与会话标识 |
| 历史成稿、官方截图、生成图片 | 不复制，换虚构示例，避免身份/隐私/来源元数据残留 |
| 旧脚本 | 按功能归并重写，不原样搬运账号定制代码 |
| 旧去标识补色脚本 | 不移植，保留来源与生成标识；上传副本只做必要压缩裁切 |

旧 inline_css.py 对应公开版同名工具；prepare_draft.py 的组装逻辑归入 publisher.py；各篇 push/update 脚本归入清单驱动的 create/update；固定出口与整目录镜像脚本归入不删除远端状态的 remote.sh。早期 shell 直连与临时 JSON 链路仅在复盘说明，不保留可误运行入口。

发布前运行 privacy_check.py，检查公开文件中的私钥、常见令牌格式、真实 IP、用户目录、媒体 ID 与敏感配置赋值。它是启发式检查，不能数学证明无敏感内容；还需人工审阅明确纳入的文件。所有示例素材均本地构造，没有使用原图元数据。

原历史里记录过凭据明文保存在本地配置和历史中的情况；本次脱敏不等于已撤回旧记录或完成凭据轮换。真实凭据是否仍有效、是否已轮换，本次没有验证，也不公开其值。
